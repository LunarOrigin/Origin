# ORIGIN : la confiance ne se décrète pas, elle se démontre. ## Présentation Origin est un projet open source visant à analyser l'origine probable des contenus numériques à l'ère de l'intelligence artificielle. Le projet a pour objectif de développer des outils transparents et explicables permettant d'analyser différents types de contenus, notamment les textes, les images et les vidéos. ## Nos objectifs : améliorer la transparence numérique, développer des outils accessibles, encourager la recherche et la collaboration, respecter la vie privée. ##
